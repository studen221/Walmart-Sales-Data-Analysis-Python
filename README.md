# Walmart Sales Data Analysis - Python

## Project Overview
Performed Exploratory Data Analysis (EDA) on Walmart sales data using Python to identify sales trends, product performance, customer purchasing patterns, promotions, holidays, and weather-related sales insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Analysis
- Monthly revenue analysis
- Best-selling products
- Sales performance by product category
- Impact of promotions on sales
- Impact of weather conditions on sales
- Customer loyalty analysis
- Holiday sales analysis

## Project Objective
To analyze Walmart sales data and generate meaningful business insights through data analysis and visualization.
